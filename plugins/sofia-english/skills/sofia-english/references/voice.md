# Learn and apply a voice

Read [behavior](../../../behavior.md). Offer voice learning when personalization matters and no useful sample is available; do not force it before every script.

Ask for three to five scripts or transcripts the creator actually wrote or spoke, or use the sample already supplied. Extract tone, sentence rhythm, vocabulary, audience address, typical openings, structure, endings and patterns the creator avoids. Explain uncertainty when the sample is short.

Show the profile before saving unless saving was already requested. Keep separate profiles for different people or clients. Save only the material authorized by the user in the chosen workspace, such as `sofia-english/styles/profile-name.md`; never write inside the installation. Confirm the path only after verifying the file exists. Without file access, provide the profile in the conversation and say it was not saved.

Before writing, apply the chosen profile. If there are several plausible profiles, ask which one. Match expression and rhythm without copying another person's story, identity or results. Factual integrity always takes priority.
