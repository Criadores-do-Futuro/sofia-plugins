# Universal rules

Rules that apply at every stage, together with [the Floor](floor.md). Each coded rule is also a review question: the line itself is what you check.

## 1. Never invent

- **UR1.** Characters are real, and you can verify who they are.
- **UR2.** Stories actually happened.
- **UR3.** Data has a source.
- **UR4.** If you don't know whom to use, say so and leave fiction out.
- **UR5.** Originality comes from the principles and the structure.
- **UR6.** An example invented to show the shape is labeled as invented and never goes into the script.

## 2. Sources you can check

- **UR7.** A real character comes with the link to the source.
- **UR8.** A data point or number comes with where it came from.
- **UR9.** A story you tell can be found with a search.
- **UR10.** It is worth spending a few seconds searching for a real story for the script.

## 3. Principles above technique

- **UR11.** A strong theme with weak technique beats perfect technique with a weak theme.
- **UR12.** Never trade a principle for a sentence that only "sounds nice".
- **UR13.** The order of the principles (Theme, Familiarity, Conflict, Curiosity, Aha) is for judging why a video holds. The order of the addictive elements, in [addictive elements](addictive-elements/README.md), is only for choosing the elements of a script. See [principles](principles.md).

## 4. Honesty in analysis

- **UR14.** Praise only when it is earned.
- **UR15.** No invented problems.
- **UR16.** Be specific: where and why.
- **UR17.** If it's good, say it's good.

## 5. Talk to the audience

- **UR18.** Use the words of the audience's bubble. No academic language.
- **UR19.** References the audience knows. What only you know doesn't count.
- **UR20.** The conflict touches whoever is going to watch.
- **UR21.** The moral connects with the viewer's life.

## 6. Never copy the theme

- **UR22.** Copy the principles, the structure and the elements. The literal theme stays out.
- **UR23.** If the original uses a famous person, use another one just as well known.
- **UR24.** If the original uses betrayal, use a conflict just as universal.
- **UR25.** The skeleton gets reused. The clothes are new.

## 7. Information always with emotion

- **UR26.** Provoking holds a person. Teaching alone does not.
- **UR27.** A script that only explains, with no conflict in the viewer's head, needs to be redone.
- **UR28.** Information goes in as a tool to build the story.

## 8. Thrift and permission in research

- Free first: the open page, the public YouTube captions, the download of a public video the creator is allowed to use.
- If the creator can paste the script, the captions or the comments, ask before fetching them another way.
- Data collectors usually cost money. Use one only if the person asks for a tool they already have, and only with their OK, after saying what it will fetch, how many items and the estimated cost.
- Install a program only after asking and explaining in one sentence what it is for.
- Never read browser cookies or passwords, never bypass a login and never ask for a password.
