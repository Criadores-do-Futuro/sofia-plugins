# Format: Visual Storytelling

This is the **recording format** axis (how the video is shot). Don't mix it up with the **structure** (the order of the argument, in [structures](../structures/README.md)) or the **archetype** (the angle, in [archetypes, niches and bubbles](../knowledge/archetypes-niches-bubbles.md)). A script has all three.

## What it is
A story told with the help of visual elements (on-screen text, animated graphics, transitions) that amplify the spoken story.

## Visual signature
- Text, graphics, icons or animated illustrations telling the story on screen
- The creator may appear, but the story moves forward through the visual elements
- Transitions and animations mark each stage of the story
- Numbers, dates and names appear written, not only spoken

## Best-fit structure
[ISC](../structures/identification-story-content.md) or [Them, Me, You, Future](../structures/them-me-you-future.md).

## Hook type this format asks for
- **FM.visual-storytelling.H.** A visual statement of consequence: the first sentence creates an image that the visuals confirm right away.

## Dominant addictive elements
[Conflict and change](../addictive-elements/conflict-and-change.md), [emotional relevance](../addictive-elements/emotional-relevance.md), [curiosity and aha](../addictive-elements/curiosity-and-aha.md).

## Writing rules
- **FM.visual-storytelling.1.** The script says which visual elements appear in each stretch and what each graphic communicates.
- **FM.visual-storytelling.2.** Spoken line and visual work together: never duplicate the same information.
- **FM.visual-storytelling.3.** Use the visual to prove what the spoken line argues.
- **FM.visual-storytelling.4.** The story has a full arc: setup → conflict → turn → resolution.
- **FM.visual-storytelling.5.** Each visual transition lands on a turn in the story.
- **FM.visual-storytelling.6.** Use real people with verifiable stories.
- **FM.visual-storytelling.7.** The aha is the moment the visual and the spoken line meet in a surprising way.
- **FM.visual-storytelling.8.** Reinforce the CTA visually, not only out loud.

## Don't confuse with
- [Voice-Over](voice-over.md): the off-screen voice tells the story; in Visual Storytelling the text and graphics tell it.
- [Cinematic](cinematic.md): tells it with shots and acting; Visual Storytelling tells it with graphic elements.
- [Green Screen](green-screen.md): a screenshot behind the creator is occasional support; in Visual Storytelling the graphics are the story's backbone.
