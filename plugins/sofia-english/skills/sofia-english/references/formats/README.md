# Recording formats

This is the **"HOW it's shot"** axis of Sofia's four-axis model. Each format has its own file in this folder.

## The 4 axes (don't mix them up)

| Axis | Question | Where it lives |
|---|---|---|
| **Virality principles** | WHY it works | [principles](../principles.md): the law; everything goes through here |
| **Script structure** | HOW the argument is organized | [structures](../structures/README.md), the 5: AIDA, ISC, Wrong Way vs. Right Way, Them/Me/You/Future, Analysis |
| **Content archetype** | WHICH angle has already proven it works | [archetypes, niches and bubbles](../knowledge/archetypes-niches-bubbles.md): A1 to A15 (numbered series, newsjacking, listicle, scene sketch, hot take...) |
| **Recording format** (THIS folder) | HOW it's shot and edited | Split screen, voice-over, cinematic, direct to camera... |

The elements that hold attention in **every sentence** (contrast, conflict, curiosity) live in [addictive elements](../addictive-elements/README.md) and cut across all four axes.

A script has all four at once. The format is what changes the **writing rules**: the same structure written for Voice-Over and for Direct to Camera produces different scripts.

> An honest note, in the same spirit as the archetypes piece: Sofia's 5 structures are built for monologue or narration. In sketch and dialogue formats (**Dialogue**, **The Office**) the suggested structure is an approximation: in those, apply the [principles](../principles.md) directly.

## How to choose

1. **Does the theme need visual proof?** (data, a screenshot, a comparison) → Green Screen, Comparison, Visual Storytelling
2. **Is the theme a real story or experience?** → Cinematic, Voice-Over, Vlog, Visual Storytelling, Behind the Scenes
3. **Is the theme an opinion, an analysis or a stance?** → Analysis, Direct to Camera, Question Box, Off-Camera Conversation, Lo-Fi
4. **Does the theme react to something that already exists?** → Split Screen
5. **Is the theme a list of quick value?** → Fast-Paced
6. **Does it need evidence of real behavior?** → Social Experiment, Vlog, Dialogue
7. **Is there an abstract idea that needs to become concrete?** → Analogy
8. **Does the hook need to stop people with a visual and then run on minimal production?** → Lazy Creative
9. **Does the idea start from a tense scene?** → Situational Conflict
10. **Are two visual languages essential, not decorative?** → Combined Format

If the creator can't produce the ideal format, pick the next best one they can actually record and say why (what the trade-off costs).

## Pairing with an archetype

The archetype (the angle) and the format (the recording) are independent choices that have to work together. Pairs that often show up together:

| Archetype | Format that usually goes with it |
|---|---|
| A1 numbered series | Fast-Paced, Direct to Camera |
| A2 newsjacking | Green Screen, Split Screen |
| A3 listicle | Fast-Paced, Green Screen |
| A4 income proof / real case | Direct to Camera, Behind the Scenes |
| A6 tutorial demo | Green Screen, Voice-Over |
| A8 controversy | Question Box, Direct to Camera |
| A14 scene sketch | Dialogue, The Office |
| A15 hot take | Direct to Camera, The Office |

## How the team uses formats

- The **scriptwriter** picks the format after the bubble and archetype and before writing, then applies that format's writing rules (FM.<format-id>.n) to every sentence and its hook type (FM.<format-id>.H) to the opening.
- When analyzing a video, Sofia identifies which format it uses (or names a combination as `Format A + Format B`).
- The **critic** and the **structure-reviewer** check that the chosen format's FM rules were followed; the **hook-reviewer** checks the FM.<format-id>.H hook type.
- When improving a script, Sofia rewrites the stretches that break the format's rules.

These are practical options, not a promise that any format guarantees results.
