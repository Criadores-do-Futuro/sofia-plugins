# Sophia English

Analyze videos and transcripts, write and review scripts, learn the creator's voice and export results in American English. Required references are bundled. No content connector is required.

## Install and use

```sh
claude plugin marketplace add bento-dev-ia/sofia-plugins
claude plugin install sofia-english@sofia-plugins
```

For Codex, use the repository catalog at `.agents/plugins/marketplace.json`. `plugin.json` and `.codex-plugin/plugin.json` describe the same version. For a manual upload, use the ZIP generated by `python3 tools/package_plugins.py` from the repository root.

Ask to analyze a video or transcript, write a script, review or rewrite a draft, learn a voice or export results. The `sofia-english` skill selects the appropriate workflow. Responses and generated files stay in English.

## Requirements and limits

Local visual preparation requires FFmpeg, ffprobe and an image-viewing tool. The analysis reference lists the `ffprobe` and `ffmpeg` commands that generate timestamped frames, contact sheets and audio when available; they do not transcribe speech or identify effects on their own. The plugin ships text only: no scripts or executables. Text work does not require these programs. Public downloads require authorization and `yt-dlp`; never use browser cookies or sessions to bypass sign-in.

Read [behavior](behavior.md). Installing programs, using paid services or sending media to third parties requires authorization. Save results and voice profiles outside the installation. There is no built-in telemetry.
