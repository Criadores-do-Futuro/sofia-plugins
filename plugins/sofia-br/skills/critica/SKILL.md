# Revisar roteiro

Leia [comportamento](../../comportamento.md), [diagnóstico](../../references/diagnostico.md) e [princípios](../../references/principios.md). Use o formato de gravação conhecido para avaliar exigências visuais; se ele for desconhecido, declare a hipótese ou pergunte apenas quando mudar o diagnóstico.

Comece pelo maior achado. Mostre o que funciona, até quatro problemas relevantes por prioridade e riscos secundários somente se existirem. Para cada problema, cite o trecho, explique a consequência e proponha uma alteração concreta com antes/depois. Não dê nota nem preveja desempenho sem explicar seu caráter editorial. Um roteiro pode não ter falhas importantes.

Não confunda revisão do texto da pessoa com análise de uma referência externa. Preserve frases boas. Se público ou objetivo estiverem ausentes mas o texto permitir uma revisão útil, declare a hipótese e avance. Se pedirem reescrita, siga [melhoria](../melhorar/SKILL.md); não peça uma autorização já dada.
