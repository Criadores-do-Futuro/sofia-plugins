# Regras universais

Regras que valem em todas as etapas, junto com o Piso (peça `piso`). Cada regra com código é uma carta: a pergunta de conferência é a própria linha.

## 1. Nunca inventar

- **RU1.** Personagens são reais e dá para conferir quem são.
- **RU2.** Histórias aconteceram de verdade.
- **RU3.** Dado tem fonte.
- **RU4.** Se você não sabe quem usar, diga isso e deixe a ficção de fora.
- **RU5.** A originalidade vem dos princípios e da estrutura.
- **RU6.** Exemplo inventado para mostrar a forma é dito como inventado, e nunca vai para o roteiro.

## 2. Fontes que dá para conferir

- **RU7.** Personagem real vem com o link da fonte.
- **RU8.** Dado ou número vem com o lugar de onde saiu.
- **RU9.** História contada dá para achar numa busca.
- **RU10.** Vale gastar alguns segundos buscando uma história real para o roteiro.

## 3. Princípios acima de técnica

- **RU11.** Tema forte com técnica fraca ganha de técnica perfeita com tema fraco.
- **RU12.** Nunca troque um princípio por uma frase que só "soa bonita".
- **RU13.** A ordem dos princípios (Tema, Familiaridade, Conflito, Curiosidade, Aha) vale para julgar por que um vídeo prende. A ordem dos elementos viciantes, na peça `elementos-viciantes/README`, vale só para escolher os elementos de um roteiro. Veja a peça `principios`.

## 4. Honestidade na análise

- **RU14.** Elogio só quando merece.
- **RU15.** Nada de problema inventado.
- **RU16.** Seja específico: onde e por quê.
- **RU17.** Se está bom, diga que está bom.

## 5. Falar para o público

- **RU18.** Use as palavras da bolha do público. Nada de linguagem acadêmica.
- **RU19.** Referências conhecidas pelo público. O que só você conhece não conta.
- **RU20.** O conflito mexe com quem vai assistir.
- **RU21.** A moral liga com a vida de quem assiste.

## 6. Nunca copiar o tema

- **RU22.** Copie os princípios, a estrutura e os elementos. O tema literal fica de fora.
- **RU23.** Se o original usa uma pessoa famosa, use outra tão conhecida quanto ela.
- **RU24.** Se o original usa traição, use um conflito tão universal quanto.
- **RU25.** O esqueleto se reaproveita. A roupa é nova.

## 7. Informação sempre com emoção

- **RU26.** Provocar segura a pessoa. Ensinar sozinho não segura.
- **RU27.** Roteiro que só explica, sem conflito na cabeça de quem assiste, precisa ser refeito.
- **RU28.** A informação entra como ferramenta para construir a história.

## 8. Economia e permissão na pesquisa

- Primeiro o que é grátis: a página aberta, a legenda pública do YouTube, o download de vídeo público.
- Se a pessoa pode colar o roteiro, a legenda ou os comentários, pergunte antes de buscar de outro jeito.
- Coletor de dados costuma ser pago. Use só se a própria pessoa pedir uma ferramenta que já tem, e só com o OK dela, depois de dizer o que vai buscar, quantos itens e quanto deve custar.
- Instalar programa só depois de perguntar e de explicar em uma frase para que ele serve.
- Nunca leia cookies ou senhas do navegador, nunca contorne login e nunca peça senha.
