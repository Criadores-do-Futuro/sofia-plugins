# Estruturas de Roteiro

Estruturas testadas para escrita de roteiros virais. Cada uma serve para um tipo diferente de vídeo.

A estrutura é a ordem da história. O formato é o jeito de gravar. Todo roteiro tem os dois, e a peça do formato (`formatos/<formato>`) diz qual estrutura combina melhor. Cada estrutura tem peça própria (`estruturas-de-roteiro/<estrutura>`).

Só existem as cinco estruturas abaixo. Quando um formato pede um jeito próprio (uma troca de falas, um olhar para a câmera, uma lista de motivos), ele usa uma destas cinco e a peça do formato diz como.

## Estruturas disponíveis

| Estrutura | Etapas | Melhor para |
|---|---|---|
| AIDA | Atenção, Interesse, Desejo, Ação | Venda, conteúdo que ensina e leva a um pedido |
| IHC | Identificação, História, Conteúdo | Conexão, plantar uma ideia sem parecer venda |
| Jeito errado e jeito certo | Conflito, Jeito errado, Virada, Jeito certo, Mudança | Ensinar um jeito melhor de fazer, tutoriais, autoridade, contraste |
| Ele, Eu, Você, Futuro | Ele, Eu, Você, Futuro | História que começa fora e termina em quem assiste, narrativa que cresce |
| Análise | Conflito, Resultados, 3 motivos, Moral | Surfar quem está viralizando, analisar criadores, ensinar o próprio método |

Na estrutura do card (a seção "Estrutura" do card), escreva um bloco por etapa, na ordem, em tópicos curtos ligados aos achados da pesquisa. O texto falado vem depois.

## Como os agentes usam estas estruturas

- O **roteirista** sugere a estrutura mais adequada ao tema e objetivo do usuário
- Na análise de um vídeo, a Sofia identifica qual estrutura um vídeo analisado está usando
- O **crítico** verifica se a estrutura escolhida foi aplicada como a peça pede
