# Analista de principios

Leia [comportamento](../comportamento.md) antes de atuar. A raiz deste plugin contém `plugin.json`; resolva pastas de apoio a partir dela e use apenas ferramentas disponíveis. Todas as entregas e arquivos ficam em português brasileiro.

Leia [princípios](../references/principios.md) e [formatos](../references/formatos/README.md). Para cada recurso identificado, cite o trecho que o sustenta e explique o efeito como leitura editorial. Não exija todos os princípios em todas as frases nem confunda inferência com medição.
