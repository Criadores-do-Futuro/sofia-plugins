# Glossário

Palavras que esta skill usa e como dizer cada uma para quem nunca estudou roteiro. Com a pessoa, use a coluna da direita. Se precisar do termo técnico, diga a explicação junto, na mesma frase.

## O vídeo

| Palavra | Como explicar |
|---|---|
| Hook | A primeira frase, a que faz a pessoa parar de rolar o feed |
| Ponte | A frase logo depois do hook, que liga a abertura ao resto |
| CTA | O pedido do fim: seguir, comentar, tocar no link |
| Tema | O assunto que faz a pessoa parar |
| Moral | A ideia que fica na cabeça de quem assistiu |
| Formato | O jeito de gravar e montar o vídeo |
| Estilo | O jeito de filmar e editar: enquadramento, cortes, texto na tela |
| Estrutura | A ordem em que a história é contada |
| Bloco | Cada parte da estrutura (por exemplo, o começo, o meio e o fim) |
| Elementos viciantes | O que faz a pessoa parar, ficar e comentar |
| Princípios | Os motivos de um vídeo prender, na ordem do método |
| Bolha | O grupo de pessoas que o vídeo quer alcançar, com os assuntos e as palavras delas |
| Lacuna de curiosidade | A pergunta que fica na cabeça de quem assiste |
| Aha | A hora em que tudo faz sentido |
| Debate mental | A pessoa fica pensando "será?" e escolhe um lado |
| Contraste | Duas coisas opostas lado a lado |
| Familiaridade (cognitiva) | Usar algo que todo mundo já conhece |
| Conflito (cognitivo) | Mostrar algo que a pessoa não esperava |
| Tema universal | Um assunto que importa para muita gente |
| Relevância emocional | Mexer com algo que a pessoa já sente |
| Pagamento (payoff) | O momento em que o vídeo entrega o que o hook prometeu |
| Punchline | A parte mais engraçada ou mais forte, no fim de uma fala |

## Os números

| Palavra | Como explicar |
|---|---|
| Normal do perfil | Quantas views um vídeo desse perfil costuma ter. Nunca diga "mediana" |
| Retenção | Quanto tempo a pessoa fica assistindo |
| Engajamento | Comentar, curtir, salvar ou mandar para alguém |
| Acima do normal | "2 vezes o normal do perfil", "perto do normal" |

## A gravação e a edição

| Palavra | Como explicar |
|---|---|
| Plano | O enquadramento: de perto, de longe, só um detalhe |
| B-roll | Imagens de apoio que passam enquanto a pessoa fala |
| Insert | Um pedaço de outro vídeo ou imagem que entra no meio |
| Corte seco (jump cut) | Corte que tira as pausas da fala e mantém o mesmo enquadramento |
| Voz off | A voz de alguém que não aparece na tela |
| Tela verde | O fundo trocado por um print, um gráfico ou outro vídeo |
| Picture-in-picture | Um vídeo pequeno dentro de outro |
| Dueto ou remix | Recurso da rede que põe o seu vídeo ao lado do vídeo de outra pessoa |
| Mockumentary | Imitação de documentário, com a pessoa olhando para a câmera como numa entrevista |
| Folha de contato | Uma imagem com vários quadros do vídeo, em ordem, para ver tudo de uma vez |

## O site e o conector

| Palavra | Como explicar |
|---|---|
| Conector | A ligação entre o chat e o site do curso. Com ele, a Sofia lê e salva os seus vídeos |
| Quadro | O planejamento, com as colunas Brainstorming, Estruturar, Revisar, Lapidar e Gravar |
| Card | Um vídeo no quadro, da ideia até a gravação |
| Cérebro | O que a Sofia aprendeu sobre o perfil: temas, palavras do público, o que funciona |
| Versão | Cada roteiro salvo no card. Nenhuma é apagada |
| Versão escolhida | A versão que vai para a gravação |
| Grifo | Um trecho marcado no roteiro, com o que mudar e por quê |
| Lapidar | Grifar o roteiro para deixar melhor |
| Referência | Vídeo de outra pessoa guardado para copiar o jeito, nunca o conteúdo |
| Molde | O texto de uma referência com as partes que mudam trocadas por {variáveis} |
| Fonte primária | O documento original, a fala gravada, o dado oficial |
