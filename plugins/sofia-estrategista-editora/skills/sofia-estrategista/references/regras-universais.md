# Regras universais

Regras que valem em todas as etapas, junto com o Piso do SKILL.md.

## 1. Nunca inventar

- Personagens são reais e dá para conferir quem são.
- Histórias aconteceram de verdade.
- Dado tem fonte.
- Se você não sabe quem usar, diga isso e deixe a ficção de fora.
- A originalidade vem dos princípios e da estrutura.
- Exemplo inventado para mostrar a forma é dito como inventado, e nunca vai para o roteiro.

## 2. Fontes que dá para conferir

- Personagem real vem com o link da fonte.
- Dado ou número vem com o lugar de onde saiu.
- História contada dá para achar numa busca.
- Vale gastar alguns segundos buscando uma história real para o roteiro.

## 3. Princípios acima de técnica

- Tema forte com técnica fraca ganha de técnica perfeita com tema fraco.
- Nunca troque um princípio por uma frase que só "soa bonita".
- A ordem dos princípios (Tema, Familiaridade, Conflito, Curiosidade, Aha) vale para julgar por que um vídeo prende. A ordem dos elementos viciantes, em [elementos-viciantes.md](elementos-viciantes.md), vale só para escolher os elementos de um roteiro. Veja [principios.md](principios.md).

## 4. Honestidade na análise

- Elogio só quando merece.
- Nada de problema inventado.
- Seja específico: onde e por quê.
- Se está bom, diga que está bom.

## 5. Falar para o público

- Use as palavras da bolha do público. Nada de linguagem acadêmica.
- Referências conhecidas pelo público. O que só você conhece não conta.
- O conflito mexe com quem vai assistir.
- A moral liga com a vida de quem assiste.

## 6. Nunca copiar o tema

- Copie os princípios, a estrutura e os elementos. O tema literal fica de fora.
- Se o original usa uma pessoa famosa, use outra tão conhecida quanto ela.
- Se o original usa traição, use um conflito tão universal quanto.
- O esqueleto se reaproveita. A roupa é nova.

## 7. Informação sempre com emoção

- Provocar segura a pessoa. Ensinar sozinho não segura.
- Roteiro que só explica, sem conflito na cabeça de quem assiste, precisa ser refeito.
- A informação entra como ferramenta para construir a história.

## 8. Economia e permissão na pesquisa

- Comece pelo que é grátis: a página aberta, a legenda pública do YouTube, o `yt-dlp` para vídeo público.
- Se a pessoa pode colar o roteiro, a legenda ou os comentários, pergunte antes de buscar de outro jeito.
- Coletor de dados é pago. Use só se a pessoa já tiver um ligado, e só com o OK dela, depois de dizer qual coletor, quantos itens e quanto deve custar.
- Instalar programa só depois de perguntar e de explicar em uma frase para que ele serve.
- Nunca leia cookies ou senhas do navegador, nunca contorne login e nunca peça senha.
