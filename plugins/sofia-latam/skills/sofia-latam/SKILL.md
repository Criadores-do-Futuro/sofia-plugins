# Sofia LATAM

Lee [comportamiento](../../comportamiento.md) antes de ejecutar cualquier flujo y [tono](references/tono-de-voz.md) para escribir. Todas las entregas, títulos y archivos generados van en español latinoamericano.

## Elige el flujo

- Video, enlace o transcripción de referencia: [analizar](analizar.md).
- Guion nuevo: [escribir](guion.md).
- Revisión o reescritura de un texto propio: [revisar y mejorar](mejorar.md).
- Aprender la voz de una persona: [estilo](aprender-estilo.md).
- Preparar el entorno o exportar resultados: [archivos y entorno](archivos.md).

Resuelve las rutas de esta habilidad desde la carpeta que contiene este archivo. La raíz del plugin contiene `plugin.json`, dos niveles arriba. Nunca dependas de variables específicas de Claude ni escribas dentro de la instalación. Los datos de trabajo van en `sofia-latam/` dentro de la carpeta elegida por el usuario. No hay un conector de contenido obligatorio.
