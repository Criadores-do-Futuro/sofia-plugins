# Formatos de grabación

Este es el eje **"CÓMO se graba"** del modelo de 4 ejes de Sofia. Hasta aquí se mencionaba en [`../conocimiento/arquetipos-nichos-burbujas.md`](../conocimiento/arquetipos-nichos-burbujas.md), pero no tenía una referencia propia: esta carpeta la aporta.

## Los 4 ejes (no los confundas)

| Eje | Pregunta | Dónde vive |
|---|---|---|
| **Principios de la viralización** | POR QUÉ funciona | [`../principios.md`](../principios.md): es la ley, todo pasa por aquí |
| **Estructura de guion** | CÓMO se organiza el argumento | [`../estructuras-de-guion/`](../estructuras-de-guion/README.md), las 5: AIDA, IHC, Modo incorrecto y modo correcto, Él, Yo, Tú, Futuro, Análisis |
| **Arquetipo de contenido** | QUÉ ángulo ya demostró funcionar | [`../conocimiento/arquetipos-nichos-burbujas.md`](../conocimiento/arquetipos-nichos-burbujas.md): A1 a A15 (serie, newsjacking, listicle, sketch, hot-take...) |
| **Formato de grabación** (ESTA carpeta) | CÓMO se graba y se monta | Pantalla dividida, narrado, cine, charla breve... |

Los elementos que enganchan en **cada frase** (contraste, conflicto, curiosidad) viven en [`../elementos-adictivos/`](../elementos-adictivos/README.md) y atraviesan los cuatro ejes.

Un guion tiene los cuatro al mismo tiempo. El formato es lo que cambia las **reglas de escritura**: la misma estructura escrita para "narrado" y para "charla breve" da guiones distintos.

> Nota honesta, en el mismo espíritu de `conocimiento/arquetipos-nichos-burbujas`: las 5 estructuras de Sofia son de monólogo o narración. En los formatos de sketch o diálogo (**Diálogo**, **The Office**) la estructura sugerida es una aproximación: ahí aplica los principios de forma directa.

## Cómo elegir

1. **¿El tema pide prueba visual?** (dato, captura de pantalla, comparación) → Pantalla verde, Comparación, Storytelling Visual
2. **¿El tema es una historia o una experiencia real?** → Cine, Narrado, Vlog, Storytelling Visual, Detrás de cámaras
3. **¿El tema es opinión, análisis o toma de postura?** → Análisis, Charla breve, Caja de preguntas, Charla de bar, Lo-Fi
4. **¿El tema reacciona a algo que ya existe?** → Pantalla dividida
5. **¿El tema es una lista de valor rápido?** → Dinamismo
6. **¿El tema necesita evidencia de comportamiento real?** → Experimento social, Vlog, Diálogo
7. **¿Hay una idea abstracta que necesita volverse concreta?** → Analogía
8. **¿El hook tiene que frenar el scroll con lo visual y el resto puede ser de producción mínima?** → Creativo perezoso
9. **¿La idea nace de una escena de tensión?** → Conflicto situacional
10. **¿Dos lenguajes son esenciales, no decorativos?** → Formato combinado

Si la persona no tiene condiciones de producción para el formato ideal, elige el segundo mejor y explica por qué.

## Combinación con arquetipo

El arquetipo (el ángulo) y el formato (la grabación) son elecciones independientes que tienen que conversar entre sí. Pares que aparecen juntos con frecuencia:

| Arquetipo | Formato que suele acompañarlo |
|---|---|
| A1 serie numerada | Dinamismo, Charla breve |
| A2 newsjacking | Pantalla verde, Pantalla dividida |
| A3 listicle | Dinamismo, Pantalla verde |
| A4 prueba de ingresos / caso real | Charla breve, Detrás de cámaras |
| A6 tutorial-demo | Pantalla verde, Narrado |
| A8 polémica | Caja de preguntas, Charla breve |
| A14 sketch de escena | Diálogo, The Office |
| A15 hot-take | Charla breve, The Office |

## Cómo lo usa Sofia

- Al **escribir el guion**, el **guionista** elige el formato después de la burbuja y el arquetipo, y antes de escribir, y aplica las reglas de escritura de ese formato en cada frase.
- Al **analizar** un video, Sofia identifica qué formato usa el video analizado.
- La **crítica** verifica que se hayan respetado las reglas de escritura del formato elegido.
- Al **mejorar** un guion, Sofia reescribe los fragmentos que rompen las reglas del formato.
- Donde no hay agentes, las pasadas de [`../pasadas.md`](../pasadas.md) hacen el mismo trabajo con las tarjetas de [`../tarjetas.md`](../tarjetas.md).
