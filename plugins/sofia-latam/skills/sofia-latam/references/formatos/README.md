# Formatos Creativos

Formato es **CÓMO se graba y se monta el video**. No lo confundas con estructura.

| Concepto | Qué define | Dónde está |
|---|---|---|
| **Formato** | Cómo se graba y se monta (pantalla dividida, narrado, cine, charla breve...) | Esta carpeta |
| **Estructura** | Secuencia narrativa del guion (AIDA, IHC, Análisis...) | [`../estructuras-de-guion/`](../estructuras-de-guion/README.md) |
| **Elementos adictivos** | Qué engancha en cada frase (contraste, conflicto, curiosidad...) | [`../elementos-adictivos/`](../elementos-adictivos/README.md) |

Todo guion tiene los tres al mismo tiempo: un formato, una estructura y varios elementos.
El formato cambia las **reglas de escritura** — la misma estructura escrita para "narrado" y para "charla breve" da como resultado guiones distintos.

## Cómo elegir

1. **¿El tema pide prueba visual?** (dato, captura, comparación) → Pantalla Verde, Comparación, Narrativa Visual
2. **¿El tema es una historia o experiencia real?** → Cine, Narrado, Vlog, Narrativa Visual, Detrás de Cámaras
3. **¿El tema es opinión, análisis o toma de postura?** → Análisis, Charla Breve, Caja de Preguntas, Charla de Bar, Producción simple
4. **¿El tema reacciona a algo que ya existe?** → Pantalla Dividida
5. **¿El tema es una lista de valor rápido?** → Dinamismo
6. **¿El tema necesita evidencia de comportamiento real?** → Experimento Social, Vlog, Diálogo
7. **¿Una idea abstracta necesita volverse concreta?** → Analogía
8. **¿Gancho visual fuerte con producción mínima después?** → Creativo Perezoso
9. **¿La idea nace de una escena de tensión?** → Conflicto Situacional
10. **¿Dos lenguajes son esenciales?** → Formato Combinado

Si el usuario no tiene condiciones de producción para el formato ideal, elige el segundo mejor y explica por qué.

## Cómo usa Sofía estos formatos

- **Al escribir** (`guion.md`): elige el formato ANTES de la estructura y aplica las reglas de escritura de ese formato en cada frase
- **Al analizar** (`analizar.md`): identifica qué formato usa el video y si sus reglas se respetaron
- **Al mejorar** (`mejorar.md`): reescribe los fragmentos que rompen las reglas del formato
