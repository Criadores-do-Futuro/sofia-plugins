# Formato: Pantalla Verde

> **Formato ≠ estructura.** El formato es CÓMO se graba y se monta el video. La estructura es la SECUENCIA narrativa del guion (ver `references/estructuras-de-guion/`). Todo guion tiene los dos.

## Qué es
El creador aparece frente a un fondo sustituido por una imagen, print, gráfico o escena real. El visual de fondo es parte activa de la narrativa.

## Estructura que combina mejor
[Análisis](../estructuras-de-guion/analisis.md) + [IHC](../estructuras-de-guion/ihc.md)

## Tipo de gancho que pide este formato
Declaración de consecuencia que apunta directamente al elemento visual de fondo.

## Elementos adictivos dominantes
[Curiosidad y Efecto AHA](../elementos-adictivos/curiosidad-y-aha.md), [Contraste](../elementos-adictivos/contraste.md), [Relevancia Emocional](../elementos-adictivos/relevancia-emocional.md)

## Reglas de escritura
1. El gancho debe mencionar o apuntar directamente al visual de fondo
2. Cada frase debe construirse como si el visual fuera prueba de lo que se está diciendo
3. Usa datos reales, prints verificables y nombres reconocibles
4. Construye suspenso antes de revelar el Efecto Ahá
5. El giro narrativo debe ser el momento en que lo visual y lo hablado se alinean
6. La moraleja debe extraerse de lo que el visual prueba, no de lo que opina el creador
7. Usa un lenguaje analítico pero accesible — como un amigo explicando algo que descubrió
8. El Llamado a la acción debe conectar el aprendizaje visual con una acción específica del espectador
