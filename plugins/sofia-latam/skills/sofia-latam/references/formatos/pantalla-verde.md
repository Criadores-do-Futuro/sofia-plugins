# Formato: Pantalla verde

> Eje **formato de grabación** (CÓMO se graba). No lo confundas con la **estructura** (la secuencia del argumento: [`../estructuras-de-guion/`](../estructuras-de-guion/README.md)) ni con el **arquetipo** (el ángulo: [`../conocimiento/arquetipos-nichos-burbujas.md`](../conocimiento/arquetipos-nichos-burbujas.md)). Un guion tiene los tres.

## Qué es
El creador aparece frente a un fondo reemplazado por una imagen, una captura de pantalla, un gráfico o una escena real. El visual de fondo es parte activa de la narrativa.

## Firma visual
- El creador recortado frente a un fondo reemplazado: captura de pantalla, publicación, gráfico, sitio web o escena
- El fondo cambia a medida que avanza el argumento
- El creador señala el fondo o se ubica al lado de lo que comenta
- Por lo general plano medio o cerrado, con el creador ocupando parte del cuadro

## Estructura que combina mejor
Análisis + IHC

## Tipo de hook que pide este formato
Declaración de consecuencia que señala de forma directa el elemento visual del fondo.

## Elementos adictivos dominantes
Curiosidad y Efecto Aha, Contraste, Relevancia emocional

## Reglas de escritura
1. El hook debe mencionar o señalar de forma directa el visual de fondo
2. Cada frase debe construirse como si el visual fuera una prueba de lo que se dice
3. Usa datos reales, capturas de pantalla verificables y nombres reconocibles
4. Construye suspenso antes de revelar el Efecto Aha
5. El giro narrativo debe ser el momento en que el visual y lo que se dice se alinean
6. La moraleja debe sacarse de lo que el visual prueba, no de lo que opina el creador
7. Usa un lenguaje analítico pero accesible, como un amigo que explica algo que descubrió
8. El CTA debe conectar el insight visual con una acción específica del espectador

## No confundir
- Pantalla dividida: el contenido externo comparte el cuadro con el creador; en la Pantalla verde es el fondo.
- Storytelling Visual: los gráficos cuentan la historia solos; en la Pantalla verde el creador siempre está en escena comentando.
- Charla breve: si el fondo es el ambiente real y no carga contenido, es Charla breve.
