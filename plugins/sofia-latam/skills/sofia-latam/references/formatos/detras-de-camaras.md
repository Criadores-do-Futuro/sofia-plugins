# Formato: Detrás de cámaras

> Eje **formato de grabación** (CÓMO se graba). No lo confundas con la **estructura** (la secuencia del argumento: [`../estructuras-de-guion/`](../estructuras-de-guion/README.md)) ni con el **arquetipo** (el ángulo: [`../conocimiento/arquetipos-nichos-burbujas.md`](../conocimiento/arquetipos-nichos-burbujas.md)). Un guion tiene los tres.

## Qué es
Video que muestra el proceso real detrás de un resultado, una creación o una rutina. Crea una sensación de acceso exclusivo y de autenticidad.

## Firma visual
- Muestra el trabajo mientras ocurre: manos, herramientas, pantalla, mesa de trabajo o set en uso
- El resultado final aparece al principio o al final, y el medio es el proceso
- Ambiente real de trabajo, con desorden y herramientas a la vista
- Habla directa o narración que explica lo que se hace mientras se hace

## Estructura que combina mejor
IHC con apertura por el resultado antes del proceso

## Tipo de hook que pide este formato
Declaración del resultado sorprendente antes de revelar el proceso ("hice {X} en {tiempo}: esto es lo que nadie muestra").

## Elementos adictivos dominantes
Curiosidad y Efecto Aha, Relevancia emocional, Conflicto y cambio

## Reglas de escritura
1. Abre con el resultado, nunca con el proceso
2. Usa el guion para construir la narrativa del proceso como una secuencia de descubrimientos
3. Incluye los errores y obstáculos reales: un detrás de cámaras sin fricción no es auténtico
4. Usa lenguaje coloquial e íntimo, como si se lo mostraras a un amigo
5. El giro narrativo es el momento en que algo salió mal (o muy bien) de forma inesperada
6. El Efecto Aha es la revelación de lo que de verdad importó en el proceso
7. La moraleja debe ser una lección aprendida en el proceso, no una teoría previa
8. El CTA debe invitar a la persona a probar el mismo proceso o a seguir para ver más detrás de cámaras

## No confundir
- Vlog: registra un día o una experiencia; Detrás de cámaras registra el proceso de UN resultado específico.
- Lo-Fi: se trata de la producción cruda; Detrás de cámaras puede estar muy bien producido, lo que lo define es mostrar el proceso.
- Pantalla verde: si el proceso aparece solo como captura de pantalla detrás del creador, es Pantalla verde, no Detrás de cámaras.
