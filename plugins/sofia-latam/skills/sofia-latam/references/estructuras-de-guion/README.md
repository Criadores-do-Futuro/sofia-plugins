# Estructuras de Guion

Estructuras probadas para escribir guiones virales. Cada una sirve para un tipo distinto de video.

## Estructuras disponibles

| Estructura | Etapas | Mejor para |
|---|---|---|
| [AIDA](aida.md) | Atención > Interés > Deseo > Acción | Videos de venta, contenido educativo con Llamado a la acción |
| [IHC](ihc.md) | Identificación > Historia > Contenido | Conexión emocional, sembrar ideas sin sonar a venta |
| [Modo Incorrecto x Modo Correcto](modo-incorrecto-modo-correcto.md) | Conflicto > Error > Giro > Acierto > Cambio | Tutoriales, posicionamiento de autoridad, contraste |
| [Él, Yo, Tú, Futuro](el-yo-tu-futuro.md) | Conflicto > Él > Yo > Tú > Futuro | Narrativa compartido, narrativa que crece |
| [Análisis](analisis.md) | Conflicto > Resultados > 3 Motivos > Moraleja | Surfear tendencias, analizar creadores, posicionar tu método |

## Cómo las usa Sofia

- Al escribir (`guion.md`), sugiere la estructura más adecuada al tema y objetivo del usuario
- Al analizar (`analizar.md`), identifica qué estructura está usando el video
- Al criticar y mejorar (`mejorar.md`), verifica si la estructura elegida se aplicó correctamente

## Nota — Estructura CORE

Hay una estructura adicional útil sobre todo para *evaluar* y ajustar guiones ya escritos: **CORE** (Conflicto, Oportunidad, Resolución, Participación). No tiene un archivo propio aquí; úsala como lente de revisión: ¿el guion plantea un Conflicto claro?, ¿muestra una Oportunidad real?, ¿entrega una Resolución satisfactoria?, ¿sostiene Participación de principio a fin?
